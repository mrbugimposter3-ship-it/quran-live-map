# Quran Live Map 🕌

The Qur'an walking a 14×14 letter grid in real time — driven by the actual clock.

- **Map app (this page):** the full live map — memory palace, Council guides, abilities,
  hour-gauntlet maze, Masjid al-Haram plan, mushaf... everything embedded, works offline.
- **Text dungeon:** [crawler/](crawler/) — the same world as a text-based dungeon crawler.

Both are installable: on Android open this site in Chrome → ⋮ → *Install app*;
on iPhone/iPad Safari → Share → *Add to Home Screen*. After the first visit it works offline.
